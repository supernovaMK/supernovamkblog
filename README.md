# supernova.log

마크다운으로 쓰고 GitHub Pages로 배포하는 개인 블로그입니다.
프레임워크 없이 Node.js 빌드 스크립트 하나로 정적 HTML을 만듭니다.

- **글쓰기** → `posts/` 폴더에 마크다운 파일 하나
- **내 정보 수정** → `src/config.js` 한 파일
- **배포** → `git push` (나머지는 GitHub Actions가 알아서)

---

## 1. 처음 한 번만 하는 준비

### 의존성 설치

```bash
npm install
```

### GitHub Pages 켜기

1. GitHub 저장소 → **Settings** → **Pages** 로 갑니다.
2. **Source** 를 **GitHub Actions** 로 바꿉니다. (`Deploy from a branch` 아님)
3. 끝입니다. 이제 `main` 에 push할 때마다 자동으로 배포됩니다.

배포 주소는 **https://supernovamk.github.io/supernovamkblog** 입니다.

> 사이트에 보이는 이름(`supernovamk.blog`)은 `src/config.js` 의 `site.title` 이고,
> 실제 접속 주소와는 별개입니다. 진짜 `supernovamk.blog` 도메인을 사서 연결하려면
> 맨 아래 "참고" 를 보세요.

---

## 2. 글 올리는 법 — 클로드에게 맡기기

가장 편한 방법입니다. **마크다운만 쓰고 나머지는 넘기면 됩니다.**

이 저장소를 연 상태에서 이렇게 말하세요.

> 새 글 올려줘. 제목은 "인덱스 하나로 응답이 10배 빨라진 이유", 태그는 데이터베이스랑 회고.
> (그 아래 본문 마크다운 붙여넣기)

그러면 클로드가 알아서 합니다.

1. `posts/2026-08-01-제목.md` 파일을 만들고 frontmatter를 채웁니다
2. `npm run build` 로 깨지는 곳이 없는지 확인합니다
3. 커밋하고 push 합니다 → 1~2분 뒤 사이트에 반영

**파일로 건네도 됩니다.** `.md` 파일을 저장소 아무 데나 두고 "이거 올려줘" 라고만 하세요.

몇 가지 알아두면 좋은 것:

- **초안으로 두고 싶을 때** — "초안으로만 만들어줘" 라고 하면 `draft: true` 상태로 두고 push하지 않습니다
- **push는 확인 후에** — 커밋·push 전에 한 번 물어보게 되어 있습니다. 바로 올리고 싶으면 "확인 없이 바로 올려줘" 라고 하세요
- **고칠 때도 마찬가지** — "지난번 인덱스 글에 문단 하나 추가해줘" 처럼 말하면 됩니다

아래 3번은 직접 하고 싶을 때 보는 내용입니다.

## 3. 글 쓰는 법 — 직접 하기

### ① 새 글 만들기

```bash
npm run new "첫 글을 씁니다"
```

`posts/2026-08-01-첫-글을-씁니다.md` 파일이 만들어집니다.
주소를 영어로 하고 싶으면:

```bash
npm run new "첫 글을 씁니다" -- --slug hello-world
```

> 파일을 직접 만들어도 됩니다. 이름만 `YYYY-MM-DD-주소.md` 형태면 됩니다.

### ② 글 쓰기

파일을 열면 맨 위에 이런 게 있습니다. 이걸 **frontmatter** 라고 부르고,
`---` 와 `---` 사이는 글 내용이 아니라 글에 대한 정보입니다.

```markdown
---
title: "첫 글을 씁니다"
date: 2026-08-01
summary: "목록에 보일 한두 줄 요약입니다."
tags: ["회고", "javascript"]
draft: true
---

여기서부터 본문입니다.
```

| 항목 | 설명 |
| --- | --- |
| `title` | 글 제목. **따옴표로 감싸주세요** (`:` 같은 문자가 들어가면 깨집니다) |
| `date` | 발행일. `2026-08-01` 형식 |
| `summary` | 목록에 보일 요약. 비워두면 본문 앞부분을 자동으로 씁니다 |
| `tags` | `["태그1", "태그2"]`. 없으면 `[]` 로 두세요 |
| `draft` | `true` 면 사이트에 안 나옵니다. 다 쓰면 이 줄을 **지우세요** |

### ③ 눈으로 확인하기

```bash
npm run dev
```

브라우저에서 **http://localhost:3000** 을 엽니다.
파일을 저장하면 자동으로 다시 만들어지니, 브라우저만 새로고침하면 됩니다.

### ④ 발행하기

`draft: true` 줄을 지운 다음:

```bash
git add . && git commit -m "새 글: 첫 글을 씁니다" && git push
```

1~2분 뒤 사이트에 올라갑니다. 진행 상황은 저장소 **Actions** 탭에서 볼 수 있습니다.

## 4. 마크다운 문법 (자주 쓰는 것만)

```markdown
## 큰 제목          ← 글 안에서는 h1(#) 말고 h2(##)부터 쓰세요
### 작은 제목

**굵게**, *기울임*, `코드`, ~~취소선~~

- 목록
- 목록
  - 들여쓴 목록

1. 번호 목록
2. 번호 목록

[링크 이름](https://example.com)

> 인용문입니다.

| 항목 | 값 |
| --- | --- |
| 속도 | 빠름 |

---   ← 구분선
```

**코드 블록**은 백틱 세 개로 감싸고 언어 이름을 적으면 색이 입혀집니다.

````markdown
```js
const hello = () => console.log('안녕');
```
````

**이미지**는 `posts/images/` 폴더에 넣고 이렇게 부릅니다.

```markdown
![사진 설명](/images/파일이름.png)
```

몇 가지 편의 기능이 자동으로 붙습니다.

- 엔터 한 번만 쳐도 줄바꿈이 됩니다
- 소제목이 3개 이상이면 글 위에 목차가 생깁니다
- 코드 블록에 마우스를 올리면 복사 버튼이 나옵니다
- 바깥 사이트 링크는 새 탭에서 열립니다

## 5. 내 정보 바꾸기

`src/config.js` 파일 하나만 고치면 됩니다. 열어보면 주석이 달려 있습니다.

| 고치고 싶은 것 | 위치 |
| --- | --- |
| 블로그 이름, 설명 | `site` |
| 첫 화면 소개 카드 · 프로필 사진 | `hero` (→ 6번) |
| "저는 이런 사람입니다" 내용 | `about` |
| "제가 요즘 하고 있는 것은…" 내용 | `now` (→ 7번) |
| GitHub·링크드인·유튜브·메일 버튼 | `socials` (→ 6번) |
| 상단 메뉴 | `nav` |
| 홈 아래 연도별 목록 | `archive` (→ 10번) |
| 활동 기록 · 커밋 버튼 | `updates` (→ 9번) |

색이나 여백을 바꾸고 싶으면 `src/assets/style.css` 맨 위 `:root` 의 변수만
건드려도 분위기가 꽤 달라집니다. 색은 구글 팔레트(`--blue` `--red` `--yellow` `--green`)를
쓰고 있고, 지도 색은 `--map-*` 변수에 따로 모여 있습니다.

## 6. 첫 화면 소개 카드 꾸미기

홈 맨 위 카드입니다. 전부 `src/config.js` 의 **`hero`** 안에 있습니다.

```js
export const hero = {
  greeting: '안녕하세요,',      // 이름 위 작은 인사
  name: '김민기',               // 크게 나오는 이름
  suffix: '입니다',             // 이름 뒤에 붙는 말
  tagline: '만드는 것보다 ...',  // 이름 바로 아래 한 줄
  intro: '읽은 것, 만든 것 ...', // 그 아래 짧은 소개 (두세 줄 권장)
  photo: '/profile.jpg',        // 오른쪽 동그란 사진
  photoAlt: '김민기 프로필 사진',
};
```

화면에서 이렇게 대응됩니다.

```
안녕하세요,              ← greeting
김민기입니다              ← name + suffix          ⬤ ← photo
만드는 것보다 ...          ← tagline
읽은 것, 만든 것 ...       ← intro
[소개 더 보기] ○ ○ ○      ← 아래 socials
```

> **너무 길게 쓰지 마세요.** 홈은 소개·최신 글·요즘 하는 것 세 블록이
> 노트북 화면 한 장에 들어오도록 맞춰져 있습니다.
> `tagline` 은 한 줄, `intro` 는 두세 줄이 적당합니다.
> 길게 쓰고 싶은 이야기는 `about.paragraphs` 나 `about.longform` 에 쓰면
> 소개 페이지(`/about`)에 들어갑니다.

### 오른쪽 동그란 자리

`hero.photo` 에 무엇을 적느냐에 따라 달라집니다.

| 값 | 나오는 것 |
| --- | --- |
| `''` | 아무것도 없음 (지금 설정) — 카드가 `이름 \| 소개+버튼` 두 칸으로 나뉩니다 |
| `'initial'` | 이름 첫 글자가 든 동그라미 |
| `'/profile.jpg'` | `static/profile.jpg` 사진 |

사진을 쓰려면 `static/` 폴더에 파일을 넣고 그 이름을 적으면 됩니다.
정사각형에 가까운 사진이 가장 예쁘고, 세로로 긴 사진도 가운데를 기준으로
동그랗게 잘라서 넣어줍니다.

### 링크 버튼 (GitHub · 링크드인 · 유튜브 · 메일)

`src/config.js` 의 `socials` 입니다. **주소를 비워두면 그 버튼은 안 보입니다.**

```js
export const socials = [
  { name: 'GitHub',   icon: 'github',   url: 'https://github.com/supernovaMK' },
  { name: 'LinkedIn', icon: 'linkedin', url: '' },  // ← 여기에 주소를 넣으면 버튼이 생깁니다
  { name: 'YouTube',  icon: 'youtube',  url: '' },
  { name: 'Email',    icon: 'mail',     url: 'mailto:daihoon5336@gmail.com' },
];
```

쓸 수 있는 `icon`: `github` `linkedin` `youtube` `x` `instagram` `mail`

## 7. "제가 요즘 하고 있는 것은…" 쓰기

`src/config.js` 의 `now.body` 에 **마크다운으로 그냥 쓰면** 됩니다.
줄 맞추거나 항목을 나눌 필요 없이, 쓴 대로 크기가 맞춰져 들어갑니다.

```js
export const now = {
  heading: '제가 요즘 하고 있는 것은…',
  updated: '2026년 8월',

  body: `
## 선착순 서비스를 개발 중입니다

### 동아리와 모임에서 쓰는 작은 예약 도구

짧은 시간에 요청이 몰릴 때 서버가 어떻게 버티는지 직접 부딪혀보고 있습니다.

## 읽고 있는 것

여기에 요즘 보는 책이나 문서를 적어두세요.
`,
};
```

화면에서는 이렇게 보입니다.

| 쓰는 법 | 나오는 모습 |
| --- | --- |
| `## 제목` | 왼쪽에 파란 선이 붙은 굵은 제목 |
| `### 작은 제목` | 그 아래 회색 작은 제목 |
| 그냥 글 | 설명 문단 |
| `- 항목` | 점 목록 |
| `**굵게**` · `[링크](주소)` · `` `코드` `` | 그대로 됩니다 |

> `body` 를 감싸는 건 따옴표(`'`)가 아니라 **백틱(`` ` ``)** 입니다.
> 여러 줄을 쓰려면 백틱이어야 합니다.
>
> 너무 길게 쓰면 세 블록이 한 화면을 넘어갑니다. `##` 세 개 정도가 적당합니다.

## 8. 소개 카드 테두리 애니메이션

소개 카드 테두리를 선 하나가 계속 돕니다.
한 바퀴 돌 때마다 **파랑 → 빨강 → 노랑 → 초록** 순으로 색이 바뀝니다.

`src/assets/style.css` 의 `.card-run-line` 에서 조절합니다.

```css
.card-run-line {
  stroke-width: 3;             /* 선 굵기 */
  stroke-dasharray: 10 90;     /* 선 길이 — 두 숫자를 더해 100이 되게 */
  animation: card-run-move 12s linear infinite,
             card-run-color 12s step-end infinite;
             /*            ↑ 12초에 네 바퀴 = 한 바퀴 3초.
                             느리게 하려면 두 숫자를 똑같이 키우세요 (예: 20s) */
}
```

색 순서를 바꾸려면 바로 아래 `@keyframes card-run-color` 의 색만 바꾸면 됩니다.

## 9. 활동 기록 (커밋 버튼)

홈의 **최근 하고 있는 것** 블록 오른쪽에 깃허브 커밋처럼 생긴 작은 버튼이 있습니다.

```
 ⊸ fa7e9a2 │ 2026.08.01
```

누르면 `/log` 페이지로 가고, 거기에 활동이 **날짜별로 세로로 쭉 쌓입니다.**
`src/config.js` 의 `updates.items` 에 하나 추가할 때마다
버튼의 해시와 날짜도 같이 바뀝니다.

```js
export const updates = {
  heading: '활동 기록',
  description: '무엇을 했는지 날짜별로 쌓아둡니다.',

  items: [
    {
      date: '2026-08-01',            // 맨 위가 가장 최근
      title: '블로그를 열었습니다',
      body: `
읽은 것과 만든 것을 남길 자리를 만들었습니다.
여기도 마크다운으로 씁니다.
`,
    },
    // 새 활동은 이 위에 추가하세요
  ],
};
```

- `date` 는 `2026-08-01` 형식으로 적으면 화면에는 `2026.08.01` 로 나옵니다
- 순서는 신경 쓰지 않아도 됩니다 — 날짜를 보고 알아서 최신순으로 정렬합니다
- 옆의 해시(`fa7e9a2`)는 날짜와 제목으로 만들어지는 값이라 손댈 필요 없습니다
- `body` 는 백틱(`` ` ``)으로 감싸고 마크다운으로 씁니다

## 10. 홈 아래쪽 연도별 목록

소개 카드 아래로 스크롤하면 쓴 글이 연도별로 쭉 나옵니다.
글을 올리면 자동으로 그 해에 들어가니 따로 할 일은 없습니다.

`src/config.js` 에서 손볼 수 있는 것:

| 값 | 하는 일 |
| --- | --- |
| `HOME_POST_COUNT` | 위쪽 '최신 글' 블록에 몇 개 보일지 (기본 3개) |
| `archive.heading` | 목록 제목 (기본 "전체 글") |
| `archive.newestFirst` | `false` 로 하면 오래된 연도부터 |

> `HOME_POST_COUNT` 를 너무 늘리면 세 블록이 한 화면에 안 들어옵니다. 3~4개가 적당합니다.

## 11. 폴더 구조

```
posts/              ← 글을 쓰는 곳 (여기만 자주 열게 됩니다)
  images/           ← 글 안에 넣을 이미지
static/             ← 프로필 사진 등 (여기 넣은 건 사이트 최상단에 그대로 올라갑니다)
src/
  config.js         ← 내 정보 (두 번째로 자주 여는 파일)
  build.js          ← 빌드 스크립트
  markdown.js       ← 마크다운 → HTML 변환
  helpers.js        ← 날짜·주소 같은 잔일
  new-post.js       ← npm run new
  dev.js            ← npm run dev
  templates/
    home.js         ← 첫 화면 (소개 + 최신 글 + 최근 하고 있는 것 + 연도별 목록)
    log.js          ← 활동 기록 페이지 · 커밋 버튼
    post.js         ← 글 본문 / post-list.js, about.js, layout.js …
  assets/
    style.css       ← 디자인 (구글 팔레트)
    app.js          ← 다크모드·검색·복사버튼
dist/               ← 빌드 결과 (자동 생성, git에 안 올라감)
```

## 명령어 정리

| 명령어 | 하는 일 |
| --- | --- |
| `npm run new "제목"` | 새 글 파일 만들기 |
| `npm run dev` | 로컬에서 미리보기 (localhost:3000) |
| `npm run build` | `dist/` 에 사이트 만들기 |
